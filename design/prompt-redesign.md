# VQA Prompt 生成范式重设计（层 1 + 层 2 完整稿）

> 版本：v1.0 ｜ 日期：2026-07-31 ｜ 状态：待确认
>
> 范围：只做层 1（能力维度+题型范式）+ 层 2（出题契约 QuestionSpec）+ 难度评分卡 + 人味模板。
> 层 3（答题者+裁判双角色）和层 4（validate.py LLM 校验）本期不做。

---

## 一、设计目标

解决当前产物 4 类问题：

1. **未预设类目走空泛默认值**——一级类目不在 `CATEGORY_GUIDES` 时，引导语只有一句"问题需要观看视频才能回答"。
2. **鲁棒性题没有抗干扰设计**——模型自由发挥，"prompt 抗干扰"题实际就是正常提问。
3. **推理题是信息抽取**——"预测性推理"实际答的是视频里说了什么，没真推理。
4. **难度名存实亡**——5 条产物全标"中等/困难"，实际字数 <30 字、单步可答。

核心思路：**把"让模型自由出题"换成"按题型骨架填空出题 + 6 维评分卡反向约束难度 + 人味模板提升真实感"**。

## 二、能力维度 × 题型范式（38 个二级类目）

### 2.1 命名映射

保留用户在前端已用的命名，后端建一层映射把它对应到内部能力维度：

| 用户前端命名 | 内部能力维度 |
|---|---|
| 视觉基础能力 | 感知层 |
| 时序能力 | 感知层（时序子集） |
| 推理能力 | 推理层 |
| 知识能力 | 知识层 |
| 鲁棒性能力 | 鲁棒性层 |
| 综合能力 | 综合层 |

用户在前端看到的还是自己的命名，后端 `ABILITY_PATTERNS` 用内部维度做查表。

### 2.2 完整 38 个二级类目骨架表

每个范式包含：**题干骨架**（模型按此填空）+ **约束**（出题硬性要求）+ **陷阱**（题容易踩的坑，用于自批）。

#### 视觉基础能力（7 个）

| 二级类目 | 题干骨架 | 约束 | 陷阱 |
|---|---|---|---|
| 动作识别 | 视频中 `[人物/物体]` 做了哪些动作？请按 `[顺序/时间]` 描述。 | 动作需动态可见，不能单帧判断；至少描述 2 个动作 | 模型可能只列 1 个动作或描述静态属性 |
| 场景理解 | 视频拍摄的 `[场所]` 中，`[物体/人物]` 的 `[空间关系/布局]` 如何？ | 需描述 ≥3 个物体/人物的关系 | 模型可能只列物体不描述关系 |
| 属性识别 | 视频中 `[物体]` 的 `[颜色/形状/数量/材质/文字]` 是什么？ | 属性需细粒度（不是"红色"而是"暗红色带金属光泽"） | 模型可能给粗粒度答案 |
| 物体识别 | 视频中出现了哪些 `[类别]` 的物体？请完整列出。 | 需列出 ≥3 个物体并说明出现位置 | 模型可能漏掉背景物体 |
| 人物识别 | 视频中有几个人？他们的 `[外貌/穿着/身份特征]` 分别是什么？ | 需区分不同人物，不能合并描述 | 模型可能只描述最显眼的 1 人 |
| 状态识别 | 视频 `[t]` 时刻 `[物体]` 处于什么状态？状态如何变化？ | 需描述状态变化过程 | 模型可能只描述静态状态 |
| 细粒度识别 | 视频 `[t1]` 处的 `[细节A]` 与 `[t2]` 处的 `[细节B]` 有何细微差异？ | 差异需具体可对比 | 模型可能给笼统的"略有不同" |

#### 时序能力（5 个）

| 二级类目 | 题干骨架 | 约束 | 陷阱 |
|---|---|---|---|
| 事件时间定位 | `[事件/动作]` 发生在视频的哪个时间点？ | 需给出具体时间或时段 | 模型可能只说"中段"不给时间 |
| 时序顺序 | 视频 `[A/B/C]` 三个事件按什么顺序发生？ | 需完整描述顺序链 | 模型可能只说 2 个事件顺序 |
| 时序计数 | 视频中 `[动作]` 总共发生了多少次？ | 需精确计数 | 模型可能估数"约 5 次" |
| 速度变化识别 | 视频 `[A]` 的速度如何变化？何时变快/变慢？ | 需描述速度变化的时间点和幅度 | 模型可能只说"变快了"不说明何时 |
| 阶段划分 | 视频可划分为几个阶段？每个阶段的核心内容是什么？ | 需给出 ≥3 个阶段及划分依据 | 模型可能只划分 2 个阶段 |

#### 推理能力（8 个）

| 二级类目 | 题干骨架 | 约束 | 陷阱 |
|---|---|---|---|
| 因果推理 | 为什么视频里会发生 `[事件]`？请描述前因后果。 | 需给出 ≥1 个因和 ≥1 个果 | 模型可能只复述事件不给因果 |
| 预测性推理 | 基于视频已发生的 `[A][B]`，预测接下来会发生什么？依据是什么？ | 预测需基于视频证据，必须说明依据 | 模型可能直接复述视频而非预测 |
| 反事实推理 | 如果视频中 `[A]` 没有发生，`[B]` 会有什么不同？ | 需明确 A 的作用机制 | 模型可能答非所问描述原视频 |
| 多步推理 | 综合视频中的 `[A→B→C]` 信息，推断 `[结论D]`。 | 需展示完整推理链 | 模型可能跳步直接给结论 |
| 空间推理 | `[物体A]` 相对 `[物体B]` 在什么方位？`[人物]` 从哪移动到哪？ | 需描述空间关系变化 | 模型可能只描述静态位置 |
| 逻辑推理 | 根据视频给出的条件 `[...]`，判断 `[结论]` 是否成立。 | 需说明判断逻辑 | 模型可能凭直觉给结论不展开逻辑 |
| 类比推理 | 视频中 `[A]` 的处理方式，类似生活中的什么场景？ | 类比需合理可解释 | 模型可能给牵强类比 |
| 抽象推理 | 视频这段内容反映了什么 `[主题/规律/道理]`？ | 需从具体内容抽象出一般性结论 | 模型可能只复述内容不抽象 |

#### 知识能力（6 个）

| 二级类目 | 题干骨架 | 约束 | 陷阱 |
|---|---|---|---|
| 常识判断 | 视频中 `[行为/现象]` 符合或违背什么生活/物理常识？ | 需指出常识依据 | 模型可能只说"不符合"不解释 |
| 专业知识 | 视频中 `[专业操作/术语]` 对应什么领域知识？是否规范？ | 需给出领域归属和规范性判断 | 模型可能给似是而非的术语解释 |
| 文化常识 | 视频 `[场景/行为]` 反映什么文化习俗或礼仪？ | 需说明文化背景 | 模型可能给笼统的"传统习俗" |
| 事实性知识 | 视频中出现的 `[人物/地标/品牌/事件]` 是什么？ | 需准确识别 | 模型可能编造不确定的事实 |
| 安全常识 | 视频 `[操作/行为]` 是否存在安全隐患？正确做法是什么？ | 需指出风险点和正确做法 | 模型可能只说"有风险"不展开 |
| 操作规范 | 视频 `[操作流程]` 是否符合规范？哪里偏差？ | 需对照规范逐点判断 | 模型可能笼统说"基本规范" |

#### 鲁棒性能力（5 个，仅 prompt 抗干扰不动视频）

| 二级类目 | 题干骨架 | 约束 | 陷阱 |
|---|---|---|---|
| prompt 注入误导 | 在 prompt 嵌入"视频中有 X"（实际没有），问：视频里真的有 X 吗？ | 误导信息必须具体，且视频里确实没有 | 模型可能顺着误导承认有 X |
| 视频文本不相关 | 视频中没有 `[Y]`，请回答：视频里出现了 Y 吗？没有请明说。 | Y 是视频中合理但实际没出现的事物 | 模型可能强行关联说"有" |
| 对立陷阱 | 用"不是 X 就是 Y，对吗？"诱导，要求模型不被二元对立带偏。 | 实际可能有第三种情况 | 模型可能顺着二元对立回答 |
| 复杂多约束 | 在 `[A约束][B约束][C约束]` 下，回答 `[问题]`。 | 约束 ≥3 个且部分互斥 | 模型可能只满足部分约束 |
| 误导性前提 | prompt 假设视频里 `[A]` 发生了（实际没有），要求模型指出前提错误。 | A 是视频中合理但未发生的事件 | 模型可能顺着前提编造 |

#### 综合能力（6 个）

| 二级类目 | 题干骨架 | 约束 | 陷阱 |
|---|---|---|---|
| 事件理解 | 视频中发生了什么事件？事件的 `[目的/结果/影响]` 是什么？ | 需综合人物/动作/场景 | 模型可能只描述动作不综合 |
| 跨模态理解 | 结合视频画面与 `[字幕/语音/文字]`，回答 `[问题]`。 | 必须同时引用画面和另一模态 | 模型可能只看画面忽略字幕 |
| 长视频理解 | 整个视频的主线是什么？可划分为几个阶段？ | 需覆盖全视频 | 模型可能只关注开头结尾 |
| 情感与意图 | 视频中人物的 `[情绪/动机/态度]` 是什么？依据是什么？ | 需给出情绪判断依据 | 模型可能只说"开心"不说明依据 |
| 视频摘要 | 请用 `[N]` 句话概括视频核心内容。 | 需覆盖关键信息不遗漏 | 模型可能只概括开头 |
| 视频评价 | 视频的 `[优点/不足/可改进点]` 是什么？ | 需具体可执行 | 模型可能给"整体不错"等空泛评价 |

## 三、QuestionSpec 出题契约 schema

模型**先产出契约再据此出题**，强制"先想清楚考察点再写题"。

```json
{
  "ability": "推理能力",
  "category2": "预测性推理",
  "pattern": "下一步预测",
  "考察点": "模型能否基于已发生事件预测后续并给出依据",
  "题干骨架": "基于视频已发生的[A][B]，预测接下来会发生什么？依据是什么？",
  "约束": ["预测需基于视频证据", "必须说明依据", "不能凭空臆测"],
  "预期答案要点": ["预测合理且具体", "依据来自视频内容", "逻辑链清晰"],
  "干扰项": null,
  "陷阱": "模型可能直接复述视频内容而非做预测",

  "难度评分": {
    "字数密度": 3,
    "推理步数": 3,
    "时间跨度": 2,
    "干扰强度": 1,
    "答案开放度": 3,
    "提问自然度": 2,
    "总分": 14,
    "档位": "困难"
  },

  "人味模板": "B-假设性提问"
}
```

**最终输出**在契约之上加 3 个字段：

```json
{
  "QuestionSpec": { ...上面那份... },
  "prompt": "基于契约生成的最终问题（应用人味模板后）",
  "参考答案": "符合预期答案要点的答案（保持客观可评，不人味）",
  "难度": "困难"
}
```

**注意**：人味只作用于 `prompt`，`参考答案`保持客观可评，不人味。这样既提升真实感又不破坏评测客观性。

## 四、6 维难度评分卡

### 4.1 评分维度

| 维度 | 1 分 | 2 分 | 3 分 |
|---|---|---|---|
| **字数密度**（prompt 字数） | <20 字 | 20–50 字 | >50 字 |
| **推理步数**（答案需要的推理） | 1 步（直接看） | 2–3 步（看+关联） | ≥4 步（多步链） |
| **时间跨度**（需观察的视频时长） | 单帧/单片段 | 多片段 | 全视频/长跨度 |
| **干扰强度**（陷阱/干扰项数量） | 无 | 1 个干扰/陷阱 | ≥2 个干扰/陷阱 |
| **答案开放度** | 封闭（事实型） | 半开放（描述型） | 开放（推理/预测） |
| **提问自然度**（人味程度） | 直问直答 | 带场景上下文 | 人味+追问+情绪 |

### 4.2 总分映射

- 6–8 分 → 简单
- 9–13 分 → 中等
- 14–18 分 → 困难

### 4.3 反向校验机制

任务要求"困难"但模型自评 <14 分 → **自动退回让模型重写**，复用现有 `MAX_RETRIES=2`。
任务要求"简单"但模型自评 >8 分 → 同样退回（避免简单题被出难）。

> **不对参考答案做字数硬约束**。事实型题（明星名字、产品名、地点、数字等）答案天然就短，强制字数会让模型凑话、引入噪声，反而破坏评测客观性。难度由 6 维评分卡（重点是推理步数、干扰强度、答案开放度）决定，与答案字数无关。

### 4.4 效果对比

**现在产物**（results.json VQA_00001）：
> "视频中展示的导尿管主体管身是什么颜色？其顶端的两个端口盖子分别是什么颜色？"

6 维评分：字数 1 / 推理 1 / 跨度 1 / 干扰 1 / 开放度 1 / 自然度 1 = **6 分**，实际是简单题，但模型标了"中等"。改造后会被退回重写为更简单的题或加难到真中等。

## 五、7 个人味模板

### 5.1 模板清单

**模板 A — 场景化追问**（第一人称代入学习场景）
> 我刚学做饭，视频里厨师那个"七上八下"是啥意思啊？为啥非要这么搞，多烫一会不行吗？

**模板 B — 假设性提问**（"假设我是…"带主观反应）
> 假设我是视频里那个发烧小孩的家长，医生说要搓手搓脚，我第一反应是"这真管用吗"，你能从原理上给我讲讲为啥这么操作能帮助散热吗？

**模板 C — 对比吐槽**（拿自己经验对比，带情绪）
> 视频里这个涮毛肚的方法跟我平时煮的不太一样啊，我都是直接扔锅里煮几分钟，这两种做法差别在哪？哪种更好？

**模板 D — 实操疑问**（"我想复刻"开头的复刻向提问）
> 我想复刻视频里这个菜，但没看明白他调料的顺序，能给我详细拆一下每一步都放了什么、为什么是这个顺序吗？

**模板 E — 闲聊式**（带"看得我有点懵"等情绪词）
> 这视频看得我有点懵，前面那个人进门为啥要先敲三下门啊？是有啥讲究还是就是礼貌？后面他手上那封信是哪来的？

**模板 F — 教学询问式**（"我家小孩问我…"第三方代入）
> 我家小孩看完这个视频问我"为啥那个人要这么做"，我一时没答上来，你能帮我讲讲背后的道理吗？最好用小孩能懂的话。

**模板 G — 复盘式**（"看完我有点没想明白…"自我复盘）
> 看完视频我有点没想明白，前面那个人明明可以直接走，为啥非要绕一圈？是不是我漏看了什么细节？

### 5.2 人味 prompt 的 6 个特征（模型按此仿写）

1. **第一人称代入**："我刚学"、"我想复刻"、"假设我是"、"我家小孩问我"
2. **带情绪/感受**："有点懵"、"第一反应是"、"管用吗"、"没想明白"
3. **多问句串联**：主问 + 追问 + 反问
4. **口语化词汇**：啥、嘛、啊、搞、弄、咋
5. **带场景假设**：假设、如果、要是我
6. **带个人经验对比**：跟我平时/我都是/我以为

### 5.3 应用策略

人味由**能力维度**决定（每个维度有适配的模板），**难度档位不再强制人味**——困难题也可能就是直问（比如"预测视频接下来会发生什么"这种推理题，直问反而比人味更清晰）。

| 能力维度 | 人味策略 |
|---|---|
| 知识能力 | 倾向人味（A / B / D / F），但模型自决 |
| 推理能力 | 人味/直问均可（B / C / G 可选），模型自决 |
| 综合能力 | 倾向人味（E / G），但模型自决 |
| 视觉基础能力 | 50% 直问 + 50% A，模型自决 |
| 时序能力 | 主要直问（时序题本就结构化） |
| 鲁棒性能力 | **直问**（鲁棒性题要精确控制干扰项，人味会冲淡干扰） |

> 取消"困难档强制人味"。模型出题时按能力维度选模板，不强制。困难题难度由 6 维评分卡保障（推理步数、干扰强度、答案开放度），不靠人味拉分。

## 六、命名映射表（用户前端命名 → 内部能力维度）

`prompt_templates.py` 内部用内部维度做查表，对外（前端、配置、产物）仍用用户命名。

```python
USER_TO_INTERNAL = {
    "视觉基础能力": "感知层",
    "时序能力": "感知层",      # 时序是感知层的子集，单列维度
    "推理能力": "推理层",
    "知识能力": "知识层",
    "鲁棒性能力": "鲁棒性层",
    "综合能力": "综合层",
}
```

`get_pattern(一级类目, 二级类目)` 查表逻辑：
1. 把用户命名转成内部维度
2. 在 `ABILITY_PATTERNS[内部维度]` 里查二级类目
3. 命中返回骨架+约束+陷阱，未命中走该维度的默认范式

## 八、风险与取舍

| 风险 | 说明 | 应对 |
|---|---|---|
| **token 消耗增加** | QuestionSpec 多一轮输出，token 约增 30% | 接受，提升质量值得 |
