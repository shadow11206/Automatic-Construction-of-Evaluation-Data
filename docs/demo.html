🎬 VQA 评测数据自动生成器

浏览器里点几下，把视频批量变成 VQA 评测数据集（问题 + 参考答案 + 难度）

🖥 全部操作在浏览器 📊 实时进度 · 断点续跑 🎯 边播视频边审核 🔌 多平台大模型

工作台 — 三步流水线一键执行

准备 → 生成 → 校验，实时进度条与滚动日志一目了然。生成中断后一键「继续生成」从断点续跑；换新视频时自动切换到「生成新任务」，历史结果永不覆盖。

类目配置 — 可视化编辑，支持 Excel 导入

类目 / 数量 / 难度权重在线编辑，内置类目提示；也可从 Excel 导入（追加 / 覆盖预览），彻底告别手改表格文件。

视频管理 — 上传、预览、勾选一气呵成

拖拽上传视频、在线播放预览、勾选参与评测；按「已使用 / 未使用 / 已导出 / 未导出」筛选，删除有引用警告。

结果审核 — 边播视频边审

多维筛选、边播视频边审核，在线改 prompt / 答案、批量标记重跑 / 删除，导出 Excel 所见即所得。

设置 — 多平台 API 一键切换

DashScope / OpenAI / OpenRouter / 智谱 / 自定义兼容接口，各自独立保存密钥与模型，一键连通性测试。

⭐ 核心能力

  • 断点续跑：按「任务+视频+类目」指纹跳过已完成条目，中断后一键继续，绝不重复消耗
  • 数据零覆盖：换视频 / 改配置后新任务自动追加，历史结果永远保留
  • 多平台模型：DashScope 原生视频理解；OpenAI 兼容平台自动「抽帧 + 图片」调用
  • 生成可停止：长任务随时停止，已生成结果即时落盘
  • 类目 Excel 导入：追加 / 覆盖两种模式，导入前预览
  • 结果导出：审核结果一键导出 Excel，含已导出 / 未导出状态追踪
  • 在线编辑：审核页直接改 prompt / 答案 / 难度，标记重跑
